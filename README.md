# LITS_HR

LeadersITS_HR is an Odoo 18 application scaffold compatible with both Odoo
Community and Enterprise. It depends only on the standard `base` module and
provides Arabic menus for employees, attendance, leaves, payroll, reports, and
settings.

Employee, contract, time-off, report, department, job-position, and time-off
type menus open their corresponding screens from the standard Odoo `hr`,
`hr_contract`, and `hr_holidays` modules.

Other actionable menus open the shared `FormTest` form screen, which is a
placeholder for future feature-specific forms.

## Installation

1. Copy the `LeadersITS_HR` directory into an Odoo addons path.
2. Restart Odoo and update the Apps list.
3. Search for **LITS_HR** and install it.
